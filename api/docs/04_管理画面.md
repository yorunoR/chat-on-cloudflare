# 管理画面

`src/admin/index.ts` で `createAdmin()` を呼び、`basePath: "/admin"` の Hono アプリ (`admin.app`) を作って `src/index.ts` でマウントしている。
drizzle-admin はリクエストボディのサイズを制限しないため、`src/index.ts` で `/admin/*` の前段に `bodyLimit` (1MB) を置いている。

## 認証

- ログイン画面の Username にメールアドレスを入力する。
- `verifyCredentials` で `admin_users` を email で検索し、`is_active` かつパスワードが一致すればログイン成功。
- セッション Cookie は `ADMIN_SECRET` で署名される。未設定・32 文字未満の場合はライブラリが起動時にエラーにする。

## 登録モデル

`admin.register(adminUsers, …)` で `admin_users` を管理対象にしている。

- 一覧: `id`, `email`, `isActive`, `createdAt` を表示、`email` で検索可能
- `createdAt` / `updatedAt` は読み取り専用
- `hashedPassword` は password ウィジェット。入力欄は常に空で、変更画面で空のまま保存すると現在の値を維持する
- `validate` で 8 文字未満のパスワードを弾き、`hooks.beforeSave` で平文をハッシュに置き換えてから保存する

ほかに次のテーブルを登録している。いずれも `createdAt` / `updatedAt` は読み取り専用。

| テーブル        | 一覧の表示カラム                            | 検索対象             | 表示名 (`toString`) |
| --------------- | ------------------------------------------- | -------------------- | ------------------- |
| `users`         | `id`, `email`, `uid`, `createdAt`           | `email`              | `email`             |
| `chat_sessions` | `id`, `uid`                                 | `uid`                | `uid`               |
| `chat_messages` | `id`, `chatSessionId`, `question`, `answer` | `question`, `answer` | (既定)              |

新しいテーブルを管理画面に出す場合は、同ファイルで `admin.register()` を追加する。
drizzle-admin は値をハッシュ化しないので、パスワードなどは `hooks.beforeSave` で変換してから保存する。

## パスワードハッシュ (`src/admin/password.ts`)

- Web Crypto の PBKDF2 (SHA-256) を使うため、Workers と Node.js の両方でそのまま動く。
- 反復回数 100,000 回 (Workers の PBKDF2 の上限)、ソルト 16 バイト、鍵長 256 bit。
- 保存形式は `pbkdf2_sha256$<iterations>$<salt hex>$<hash hex>`。
- 検証は定数時間比較で行う。保存値の反復回数が上限を超えるなど不正な形式の場合は `false` を返す。

## 管理者ユーザーの作成

```sh
pnpm admin:create <email>
```

パスワードは実行時に非表示で 2 回入力する (TTY 必須)。同じメールアドレスが既にあればパスワードを更新し、有効化する。
